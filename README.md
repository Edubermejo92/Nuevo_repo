## padelpulselive.com

Fuente y documentación de la web de PadelPulse Live, la app marcador de
pádel con árbitro IA y voz para Android y Wear OS.

El sitio en producción funciona sobre **WordPress** (tema Twenty
Twenty-Three); el contenido de las páginas es el porte del sitio estático
que hay en `web/`.

- `web/` — fuente estática del sitio (portada, tres páginas legales, 404,
  `robots.txt`, `sitemap.xml`, `.htaccess` y `assets/`).
- `wordpress/404-template.html` — plantilla de bloques que sirve el 404 en
  WordPress.
- `docs/revision-responsive.md` — revisión responsive, correcciones
  aplicadas y tareas pendientes.
